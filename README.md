## Public boundary

Examples use placeholders. Real tokens, client secrets, private keys, webhook credentials, bot tokens, database credentials, private endpoints, recovery material, personal information and administrative identifiers stay private.

Microsoft, Xbox, Minecraft/Mojang, Discord and other third-party systems remain external service boundaries.
